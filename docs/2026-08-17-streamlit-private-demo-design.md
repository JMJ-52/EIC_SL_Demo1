# Streamlit 비공개 시연 앱 설계

## 목적

기존 FastAPI 운영 사이트와 분리된 `SL/` Streamlit 앱을 만든다. Streamlit
Community Cloud의 비공개 초대를 첫 접근 경계로 사용하고, 초대 사용자가 일반
타당성 검토와 실제 OpenAI 분석 흐름을 시연할 수 있게 한다. 관리자는 별도 로그인
후 관리자 전용 기능을 확인할 수 있다.

## 범위

포함한다.

- 첫 화면의 `초대 사용자` 및 `관리자` 진입 버튼
- 초대 사용자의 일반 기능: 프로젝트 생성·수정·삭제, 문서 업로드와 원본 미리보기,
  설비 수동 추가·수정, OpenAI 기반 식별·Factor 평가·재평가, 결과 보고서, 확정·보류·재개,
  보고서 버전 이력
- Cloud Secrets에 저장한 관리자 ID 및 비밀번호를 이용한 관리자 로그인
- 관리자 전용: 사용자 승인/반려, 로그인 및 활동 로그, 이용 통계, 단종 검토
  승인/반려, 승인 장비 목록과 내보내기 화면
- 기존 `docs/demo/`의 샘플 문서를 사용하는 라이브 시연
- 설비별 독립 AI 챗봇, Tavily 웹 검색 기반 근거 수집, 기술 의견 및 리스크 체크리스트
- Siemens·ABB·Hitachi 공급사 웹의 실시간 단종 정보 조회 결과 미리보기
- TMEIC·TOSHIBA·MELCO PDF 확인 요청 폼과 이메일 발송 내용 미리보기

제외한다.

- 실제 사용자 가입 및 승인 정보의 영구 저장
- 정기 단종 수집
- 운영 SQLite DB 및 실제 운영 업로드 파일 접근, 외부 DB 및 파일 저장소 연결
- 개인 API 키 입력

## 접근 제어와 역할

Cloud의 앱 설정은 `Only specific people can view this app`으로 설정한다. 초대는
앱 외부의 1차 접근 통제이며, 앱은 아래 두 역할을 제공한다.

1. `guest`: 첫 화면에서 `초대 사용자`를 선택한 세션. 일반 시연 화면만 사용한다.
2. `admin`: 관리자 ID와 비밀번호 검증에 성공한 세션. 일반 화면과 관리자 화면을
   모두 사용한다.

관리자 비밀번호와 OpenAI 키는 소스 코드, Git 저장소, 화면, 로그 및 오류 메시지에
절대 포함하지 않는다. 관리자 인증 실패 메시지는 ID와 비밀번호 중 어느 값이 틀렸는지
구분하지 않는다. 관리자 페이지를 직접 탐색해도 현재 세션 역할이 `admin`이 아니면
접근을 거부하고 첫 화면으로 되돌린다.

Cloud Secrets에는 `ADMIN_USERNAME`, `ADMIN_PASSWORD`, `OPENAI_API_KEY`,
`OPENAI_MODEL`, `TAVILY_API_KEY`, `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`,
`SMTP_PASSWORD`, `REQUEST_RECIPIENT_EMAIL`을 정의한다. 실제 값은 Cloud의 Secrets
관리 화면에서만 입력하며, 이 저장소에는 예시값도 저장하지 않는다.

키는 데모 전용 OpenAI 프로젝트의 저한도 키를 사용한다. 호출 횟수 제한은 외부 DB가
없으므로 세션 단위이며, 새 브라우저/재연결로 초기화될 수 있다. 따라서 공급자 측의
예산 한도가 최종 비용 통제 수단이다.

## 화면과 데이터 흐름

`streamlit_app.py`는 역할에 따라 화면을 분기한다.

```text
Landing
 ├─ 초대 사용자 → 일반 대시보드 → 문서 업로드 → AI 분석 → 보고서
 └─ 관리자 → 관리자 로그인 → 관리자 대시보드 → 관리 기능
```

일반 화면의 프로젝트, 설비, 첨부파일 메타데이터, AI 결과, 보고서 버전 및 사용자
작업은 Streamlit 세션 상태에만 보관한다. 사용자가 세션을 새로 열거나 앱이 재시작되면
초기 데모 데이터로 돌아간다. 업로드 파일은 현재 세션에서 문서 미리보기·재분석·챗봇
근거 확인에 필요한 시간 동안만 임시 디렉터리에 보관하고, 세션 종료 또는 앱 재시작
시 삭제한다.

관리자 화면은 시연용 초기 데이터로 시작한다. 관리자 승인/반려 및 단종 검토 변경은
현재 세션에서 즉시 반영되지만 영구 저장하지 않는다. 로그와 통계도 해당 세션의
시연 데이터를 기반으로 갱신한다. 공급사 웹 수집은 실제 외부 사이트를 조회해 결과를
미리보기로 보여 주지만 검토 큐나 장비 목록에 자동 등록하지 않는다. PDF 확인 요청은
Secrets의 고정 `REQUEST_RECIPIENT_EMAIL` 주소에 SMTP로 실제 발송한다. 수신자 주소는
화면에서 변경할 수 없으며, 발송 이력은 현재 세션에서만 보관한다.

## 구성 요소

- `SL/streamlit_app.py`: 앱 진입점, 페이지 라우팅, 역할 확인
- `SL/auth.py`: Secrets 기반 관리자 검증과 세션 역할 전환
- `SL/demo_data.py`: 초기 사용자·단종 검토·프로젝트·설비·통계·보고서 데모 데이터
- `SL/session_store.py`: 세션 내 프로젝트, 설비, 사용자 승인, 검토 큐, 이력 및 로그를
  초기화·조회·변경하는 저장소 경계
- `SL/ai_demo.py`: PDF/PPTX/XLSX 텍스트 추출, OpenAI 식별·평가·기술 의견·리스크
  체크리스트·설비별 챗봇, Tavily 근거 검색, 세션별 호출 한도와 임시파일 정리
- `SL/discontinuation_demo.py`: 공급사 웹 수집 결과 미리보기와 고정 담당자에게 보내는
  PDF 확인 요청 SMTP 전송. 결과와 발송 이력은 세션 밖에 저장하지 않음
- `SL/pages/general.py`: 프로젝트 목록, 기본 정보, 문서 업로드·미리보기, 설비 편집,
  AI 검토·재검토, 보고서, 상태 변경 및 이력 화면
- `SL/pages/admin.py`: 사용자 승인·반려, 로그인·활동 로그, 통계, 단종 검토 큐,
  승인 장비 목록 및 내보내기 화면
- `SL/tests/`: 인증, 역할 차단, 시연 데이터 변경, API 키 미노출을 검증하는 테스트

## 오류 처리

- Secrets 누락: 어떤 값이 비어 있는지 공개하지 않고 관리자 또는 AI 기능을 사용할 수
  없다는 안내를 표시한다.
- 잘못된 관리자 자격 증명: 일반화된 실패 안내만 표시한다.
- AI 또는 웹 검색 호출 실패: 키·원문·내부 예외를 노출하지 않고 재시도 안내를 표시한다.
- 공급사 웹 수집 실패: 공급사 사이트 오류를 내부 세부 정보 없이 안내하고, 재시도 또는
  샘플 결과 보기 선택지를 제공한다.
- 이메일 전송 실패: SMTP 비밀번호·서버 응답을 공개하지 않고, 전송하지 못했다는 안내와
  재시도 방법만 표시한다.
- 업로드 형식 또는 크기 초과: PDF/PPTX/XLSX만 받고 개별 파일 및 총 크기 제한을
  적용한다.
- 세션 초기화: 새로고침·세션 만료·앱 재시작으로 시연 변경이 사라질 수 있음을 첫
  화면과 관리자 화면에 명시하고, 초기 데모 데이터로 안전하게 복구한다.

## 검증 기준

- 초대 사용자 역할은 일반 화면을 사용할 수 있고 관리자 화면을 열 수 없다.
- 올바른 Secrets 자격 증명은 관리자 역할을 부여하고 모든 관리자 메뉴를 노출한다.
- 프로젝트·설비·첨부파일·상태·보고서 이력과 관리자 변경은 현재 세션에서 즉시
  반영되며, 새 세션에서는 초기 데모 데이터로 복구된다.
- AI 식별·평가·기술 의견·리스크 체크리스트·설비별 챗봇은 `OPENAI_API_KEY`가 있을
  때만 실행한다. 웹 근거 검색은 `TAVILY_API_KEY`가 있을 때만 실행한다. UI·로그·테스트
  출력에는 어떤 키도 없다.
- 공급사 웹 수집은 실제 조회 결과를 미리보기로 보여 주며, PDF 확인 요청은 고정 담당자
  주소에 실제 SMTP 전송하고 성공 또는 실패 상태를 보여 준다. 두 기능 모두 DB 기록을
  하지 않는다.
- 기존 운영 경로, `.env`, `data/` 파일을 읽거나 수정하지 않는다.
